# 桃园三国（全十一章 · 193 年徐州 → 228 年五丈原）

吞食天地式网页 RPG，全主线可通。引擎/数据分层结构（按《整体规划》06 文档）。纯静态网页版：存档在浏览器 localStorage，无需任何后端。

## 内容

- **序章~二章**：徐州剿匪 → 父仇之火（于禁）→ 三让徐州（纪灵、张辽演出战）
- **第三~五章**：寄人篱下（许田围猎、煮酒论英雄）→ 风云再散（分线关羽、白马坡连战）→ 千里走单骑（五关斩六将、古城释疑；编成所开放）
- **第六~八章**：卧龙出山（檀溪限时脱出、三顾茅庐；诸葛亮任军师、计策书）→ 火烧博望（火攻、护送百姓、赵云长坂五连战）→ 赤壁鏖兵（舌战群儒、草船借箭、借东风、华容义释）
- **第九章 · 荆南四郡**：桂阳/武陵/长沙/零陵；黄忠收服战（3 回合逼至三成血）、魏延反水；弓系武器上线；黑市游商
- **第十章 · 西川风云**：涪城宴 → 落凤坡（庞统剧情杀）→ 张任 → 马超收服 → 成都受降 → 定军山连战（夏侯渊→张郃）；铁匠铺强化开放；龙泉系列
- **终章 · 出师未捷**：出师表 → 天水收姜维 → 街亭之失（固定败战+挥泪斩马谡+限时撤退）→ 空城计 → 连破三阵 → 五丈原八卦阵（按阵眼顺序破阵）→ 司马懿三形态决战 → 星落秋风五丈原（谢幕）
- **收集**：6 件情怀名品（雌雄双股剑/青龙偃月刀/丈八蛇矛/龙胆枪/落日弓/七星杖）+ 七星剑/诸葛巾彩蛋，获取方式：剧情赠送 / 隐藏宝箱 / 汉中军需
- **系统**：等级经验（累计制 EXP(L)=80×L^1.8）、成长率加点、谋略习得（含全员通用计策：火计 Lv6/落石 Lv10/水计 Lv14）、技能随等级缩放（×(1+(Lv-1)×3%)）、**装备五槽**（武器/防具/头盔/护腿/饰品）+装备仓库（实例化）+武器强化（铁匠铺）、防御指令、敌人掉落、宝箱、图鉴、编成所（出战/后备/军师/阵形）、演出战/连战/波次战/收服战/固定败战/多形态 Boss、限时脱出、小游戏（围猎/借箭）、存档 v5 三档位（v2/v3/v4 自动迁移，v1 提示不兼容；旧单档 key 自动迁入槽 1）
- **设施**：徐州城/小沛 老兵=编成所（出战↔后备调换、阵形、军师）；下邳 铁匠=武器强化（精铁×1+费用，必成，上限+5）；**酒馆**（徐州/许都/成都）=樗蒲赌局（五木黑白，赌注 30/50/100，本钱不足 500 不招待；首次全黑赠成长武器"时运"——攻随等级成长、攻击偶发眩晕/起火/追加/回血；首次全白扣 500 金但获藏宝洞线索）；**训练所**（徐州/许都/成都）=花钱买经验
- **0724+ 增强**：城内规整道路+建筑一字招牌（客/武/装/药/酒/训/府）+告示牌+村民指路（指引四件套）；徐州城全设施室内下钻（太守府大殿+六店铺）；商店拆分武器店/防具店且每城含上一代装备；出售 50%；野怪掉钱上调；野外迷宫山洞×5（序章保底铜剑/布衣/皮甲，另有樗蒲藏宝洞）
- **表现**：像素立绘（行走图/战斗图，engine/sprites.js 分层合成）+ 对话头像（assets/portraits/，说话人自动匹配）+ 章节通关插画（assets/illust/，章节切换与终章谢幕时全屏展示，点击继续）。美术由 tools/gen_art.py 程序生成，想换图直接替换同名 PNG 即可
- **UI（0726+）**：像素国风 UI 素材（assets/ui/，9-slice 面板/按钮/牌匾/顶条 + 十字键 AB 贴图 + title_bg/splash 大图）；一体化布局——整个游戏屏幕是一整块画面（HUD 浮顶部、对话框浮底部、战斗 UI 浮画面上），只有底部按键区独立；视野 15×14 格；开屏页（splash）→ 标题页 → 游戏

## 运行

**本版为纯静态网页，无需 Python、无需局域网。**

1. 本地玩：双击 `启动游戏服务.bat`（或 `python server.py`）后开 `http://localhost:8322`；也可以直接用任意静态服务器托管本目录
2. 发布玩：把整个目录上传到任意静态托管（GitHub Pages / Cloudflare Pages 等），手机 4G 打开网址即玩
3. 存档保存在各自设备的浏览器 localStorage 里，换设备不带存档；清浏览器数据会丢档

**旧版 SQLite 存档**（`rpg.db`）不再被读取，留着仅作备份。

**可选工具**（不玩游戏不用装）：

- 重新生成美术：`pip install Pillow` 后 `python tools/gen_art.py`
- 无头数值测试：需自行安装 Node 20+，然后 `node tools/test_headless.js`
  （本包未含便携版 Node；`python tools/validate.py` 数据校验无此依赖）

## 操作

- 触屏：十字键移动，A 对话/确认/开宝箱，B 菜单
- 电脑：方向键/WASD 移动，Enter/Z 确认，Esc/X 菜单
- 菜单里有：状态 / **装备**（仓库穿戴/卸下/换装）/ 道具 / **谋略**（习得列表+MP消耗+效果）/ 任务 / 编成（占位）/ **存档** / **读档**（均为三档位选择；读档与覆盖已占用槽前有确认弹窗）
- 商店：购买装备入仓库；武器店/防具店/杂货店均有"**出售**"入口（售价=买价 50%）

## 文件结构

```
rpg/
├── server.py           # 后端（静态托管 + 存档 API，SQLite 存 rpg.db）
├── index.html          # 页面与样式
├── engine/             # 引擎层
│   ├── core.js         # 主循环/状态机/输入/画布相机/roundRect 垫片
│   ├── map.js          # 地图渲染/行走/NPC/传送/遇敌/宝箱/触发器
│   ├── battle.js       # 回合制战斗（防御/自动队友/敌方AI/演出战）
│   ├── ui.js           # 对话框/面板/商店/旅店/菜单/编成所/铁匠铺/图鉴/HUD
│   ├── minigame.js     # 小游戏框架（hunt 围猎 / collect 借箭）
│   ├── save.js         # 存档 v5 三档位读写 + 版本迁移（旧单档自动迁入槽 1）
│   ├── sprites.js      # 像素立绘渲染器（点阵分层合成，角色外观见 data/heroes.js 的 look）
│   └── formulas.js     # 纯逻辑公式（经验/成长/伤害/治疗/逃跑率）
├── data/               # 内容层（新章节只加这里）
│   ├── heroes.js       # 角色模板（成长率/习得表）
│   ├── skills.js       # 谋略定义
│   ├── enemies.js      # 敌方单位 + 战斗编组 + AI 类型
│   ├── items.js        # 装备/道具/商店库存（含返魂香/精铁）
│   ├── text.js         # 剧情台词集中
│   ├── chapters.js     # 章节注册表 + 任务链文案
│   ├── formations.js   # 阵形定义（鹤翼/鱼鳞/锋矢/冲轭/八卦）
│   ├── portraits.js    # 说话人 → 对话头像注册表（tools/gen_art.py 自动生成）
│   └── maps/           # 每图一文件（网格+NPC+传送+宝箱+触发器）
├── assets/             # 生成的美术资产（tools/gen_art.py，可直接替换同名 PNG）
│   ├── portraits/      # 对话头像（144×168 像素胸像，透明底）
│   ├── illust/         # 章节通关插画（480×270）+ end.png 谢幕图
│   └── ui/             # 像素 UI 素材（9-slice 面板/按钮/牌匾/顶条、十字键 AB、title_bg/splash）
├── tools/
│   ├── validate.py     # 数据校验（python tools/validate.py）
│   ├── sprite_preview.py # 立绘 ASCII 预览（python tools/sprite_preview.py）
│   ├── gen_art.py      # 美术资产生成器（需 Pillow，生成头像+章节插画）
│   └── test_headless.js# 无头数值测试（需自装 Node 20+：node tools/test_headless.js）
└── backup_v1/          # 序章初版 data.js/game.js 备份
```

## 扩展方向

- 加章节：只加 data/ 文件 + chapters.js 注册（铁律：不改引擎）
- 需要新机制（如连战/波次）时先加引擎能力，数据层再使用
- 跨设备云存档：再接一个后端或对象存储即可，存档结构不变
