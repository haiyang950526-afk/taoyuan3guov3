# A · 华容道杀放（ch08 改造）

## A-0 现状

`ch08_huarong` 单场 Boss 战（曹操亲卫队），`forceEndRound: 6` 后按胜负
直接给两版义释台词、赠铜雀、进第九章。**玩家没有任何选择。**

## A-1 设计总览（拉长为四拍）

```
【军令状】（新场景，夏口） → 【截击残军】（新编组，waves）
  → 【亲卫队战】（现有编组，forceEnd 6 后改为进入抉择事件）
  → 【马前三抉：放 / 杀 / 擒】 → 【复命缴令】（收尾演出）
```

- 军令状是伏笔容器：诸葛亮"夜观乾象，操贼未合身亡"（演义原话），
  为后面"杀不成"预先给了**合理性**——不是系统不让杀，是天数未到。
- 三抉全部通向"曹操北还"（洪流），但演出、奖励、回响各不相同；
  "杀"与"擒"给足玩家动作与情感，让"放"从系统强制变成人物抉择。

## A-2 节点：军令状（新，风味选择）

- **触发点**：赤壁火起、乌林追击之后，夏口营中诸葛亮分派截杀任务
  （新场景，挂在 `ch08_xiakou` 诸葛亮 NPC 的 branches 上）。
- **对话**：

```js
lingzhuang: ["诸葛亮：曹操新败，必走华容小道。云长——",
             "关羽：军师放心，关羽此去，必取曹操首级回来！",
             "（诸葛亮欲言又止，羽扇轻摇：夜观乾象，操贼未合身亡……）",
             "诸葛亮：既如此，请立军令状。",],
```

- **选项**（风味，不改结果）：

| 选项 | 效果 | 回响 |
|---|---|---|
| "拿不下曹操，甘当军令！" | `set hr_pledge=1` | 历史线。复命时多一段"缴令"张力 |
| "……军师似乎话里有话？" | 无 set | 诸葛亮笑而不答；复命时台词呼应"你早看出来了？" |

## A-3 节点：截击残军（新编组，加长玩法）

- 进入华容道地图后、遭遇曹操前，新增一场 `ch08_huarong1`：
  `waves: [["华容曹兵","华容曹兵"],["华容曹兵","华容曹兵","华容曹兵"]]`，
  台词演出"曹军自相践踏，死者蔽道"——让玩家亲手把曹操打成真正的
  穷途末路，马前一抉才有分量。战利品照旧（华容曹兵掉落）。

## A-4 节点：马前三抉（核心改造）

- 现有 `ch08_huarong` 编组不动；`forceEndRound: 6` 后 `onForceEnd`
  的两支改为**先弹抉择事件**（win=杀到马前 / lose=拦于马前，台词微调，
  流程相同）。
- **抉择演出**：

```js
huarongAsk: ["（曹操坐骑中箭，滚鞍落马。左右亲卫，已不足十人。）",
             "曹操：云长……别来无恙。",
             "张辽：云长兄！当年白门楼，辽已当死，是谁保我一命——今日，还到文远身上！",
             "（青龙偃月刀，缓缓抬起。全场的呼吸都停了。）",],
```

- **三选项**：

| 选项 | 演出与结果 | 奖励 |
|---|---|---|
| **放** | 历史线。长叹放行，"昔日之恩，今日已报，从此两不相欠。" | 铜雀（现有遗物，挪至此支）+ `hr_choice=release` |
| **杀** | 刀落至半——闪回许田围猎那口没出鞘的刀（若 ch03 伏笔已接，台词差分）；关羽终是缓缓收刀："杀你……如杀关某自己。"曹操呆立良久，拜谢而去 | 铜雀 + **关羽 攻+2**（"斩过心魔"）+ `hr_choice=stayed` |
| **擒** | 绑了就走。行不十里，许褚残部拼死劫道，张辽断后死战——乱军中曹操滚鞍脱缚，北邙方向尘烟大起：北方已乱。关羽按剑良久："……天意。"释缚纵之 | **信物"孟德手书"**（新遗物，与铜雀二选一）+ `hr_choice=seized` |

- 三支共用收尾台词（演义原话，天然给所有分支兜底）：

```js
huarongBack: ["（夏口。关羽回营缴令。）",
              "诸葛亮：亮夜观乾象，操贼未合身亡——留这桩人情，教云长亲手做了，也是美事。",
              "（华容一道，义字千秋。）",],
```

- **杀意闪回（需 ch03 伏笔，可选）**：ch03 许田围猎加一个小 ask——
  关羽欲斩曹操，刘备**拦 / 不拦**（不拦则被周仓按住，纯演出）。
  `set hr_xutian=1` 时，"杀"支闪回台词替换为：

```js
flashback: ["（许田围猎，那口被按住的刀……主公当日按的是刀，今日按不住的是关某自己。）",],
```

## A-5 华容道 · flags 与回响

| flag | 含义 | 回响点 |
|---|---|---|
| `hr_choice` | `release / stayed / seized` | ① 终章谢幕词差分 ② 未来夷陵/麦城篇提及（如曹操厚葬关羽时的台词） ③ 遗物收藏页文案 |
| `hr_pledge` | `1` | 复命缴令多一段军令状张力 |
| `hr_xutian` | `1` | "杀"支闪回台词差分 |

- 关羽 攻+2 用 03 文档的 `statUp` 引擎先例（A 案）实现；不做则改赠玉佩（B 案）。
- **奖励互斥**：铜雀与"孟德手书"二选一——全收集玩家必须二周目，配合
  NG+ 讨论（见会话）正合适。

## A-6 华容道 · 所需改动

| 项 | 内容 | 成本 |

| 编组 | 新增 `ch08_huarong1`（waves 截击战） | 纯数据 |

# B · 借的卢救庞统（ch10 改造）

## B-0 现状

`ch10_luofeng` 踩点 → `scriptedLoss` 固定败战 → 庞统剧情杀 +
`{ leave: "庞统" }`。**必死，无选择。** 的卢马已是游戏内遗物
（`items.js:59`，速+5，唯一）。

## B-1 设计总览（拉长为五拍）

```
【让马】（涪城出发前，ask） → 【落凤坡伏击战】（现有 scriptedLoss，复用）
  → 借 = 历史殒命 ｜ 不借 =【抢救】（伤而不死） →【寻药】（往返 mini-arc）
  →【送别】（庞统退出战斗序列，成都养伤） →【病榻回响】（章末 + ch11）
```

- 关键守衡：**庞统活，但武将位置照样空出来**（伤退离队，与麦城关羽下线
  同模）——玩家救的是人命，不是阵容，历史格局不破。
- 的卢两头都是传奇：借了，"妨主"应验于马（马代主死）；没借，
  檀溪救主的名驹留着，落凤坡少一段因果。

## B-2 节点：让马（涪城出发前）

- **触发点**：`q10: luo1`（穿落凤坡迂回）阶段，涪城/野外出发口，
  新增送行事件。
- **对话**：

```js
lendHorse: ["（庞统的坐骑又老又瘦，走落凤坡那样的险路，实在勉强。）",
            "刘备：士元——骑我的的卢去吧。此马檀溪跃过三丈，灵性得很。",
            "庞统：主公的御马，统，怎敢当……",],
```

- **选项**：

| 选项 | 效果 |
|---|---|
| "军情紧急，先生莫推。"（借） | `set pt_horse=1`；若背包有【的卢马】则标记借出 |
| "军师说的哪里话，自家的马骑着踏实。"（不借） | 无 set |

- 演出细节（借支）：张任伏兵台词差分——"**见白马者，便是刘备，射！**"
  （演义原句），让玩家心头一沉：这马，是把人替了。

## B-3 节点：落凤坡伏击战（复用）→ 双分支结局

- 编组 `ch10_luofeng` 与 `scriptedLoss` 不动；`onLoss` 按 `pt_horse` 分流。

**借支（历史殒命）**：现有 `pangtongDeath` + `leave 庞统` 照旧；追加：
的卢马从背包移除（若在），演出"白马与主，同殁于坡"——
"妨主"之言，应验在马身上，不轻不重，正好。

**不借支（伤而不死）**：

```js
pangtongWounded: ["（乱箭齐发！庞统座下驽马惊蹶，将他掀入山涧——）",
                  "（魏延、周仓冒死突入箭雨，硬是把人抢了回来。）",
                  "庞统：（气若游丝）马……马死了……主公的马若在……",
                  "（庞统身中数箭，命悬一线。军中没有能救他的人。）",],
```

- 此支**不加** `leave`（先留一口气），进入寻药 arc。

## B-4 节点：寻药 mini-arc（拉长玩法的主体）

- **第一步 · 军医束手**：随军医官（新 NPC）台词——"箭伤入腑，非**仙草露**
  吊命、**金疮药**续伤不可。军中……没有。"
- **第二步 · 筹药**（两条路，可叠加）：
  - **药方路**：交出【仙草露×1 + 金疮药×2】（仙草露现于 ch03 左慈/
    ch05 桃花源等彩蛋，老玩家背包里多半有——让彩蛋积累产生救命的回报）。
  - **故人路**：若 ch03 已做"华佗授五禽戏"桥段（03 文档），华佗弟子闻讯
    赶到，免药材直接施救——**三年前的善举，今日救人一命**。
- **第三步 · 结果**：
  - 救成 → `set pt_alive=1`：庞统稳住性命，但箭伤入骨，**从此不能临阵**。
  - 药不够/不救 → `set pt_coma=1`：昏迷不醒，军士以板车护送回成都
    （保底处理，不二次杀他——玩家已经选择了不借马，不再惩罚到底）。
- 两支都接 `leave 庞统`（退出战斗序列）+ 诸葛亮入川台词微调
  （"庞统伤重，军无谋士"——诸葛亮照样来，洪流不破）。

```js
pangtongSaved: ["（仙草露吊住心脉，金疮药续住伤处。三日三夜，人，救回来了。）",
                "庞统：统这条命……是主公的马换来的——他没借马，倒是救了我。",
                "（然箭伤入骨，双臂难张。凤雏之翼，折于落凤坡。）",
                "（军前不可一日无谋——诸葛亮自荆州星夜入川。）",],
```

## B-5 节点：送别与病榻回响（长线）

- **章末送别**（进成都受降后）：庞统登车东归养伤，与刘备执手——
  "统在西川没做完的事，托付孔明了。" 若 `pt_coma` 则为抬送版。
- **ch11 病榻探看**（北伐章，成都/汉中新 NPC 事件，可选）：
  - `pt_alive`：庞统扶杖而出——"若统尚能骑马，必不叫伯约孤身守街亭……"
    赠遗物**"凤雏手卷"**（军师计策伤害 +10%，与六韬残页同型不同名，可共存）；
  - `pt_coma`：榻前烛火，诸葛亮点完七星灯后静坐良久（呼应 01 彩蛋七星灯）。
- **麦城篇接口**（若 10 文档立项）：庞统活着不改变麦城任何流程
  （人在成都养伤），仅在 `pt_alive` 时给 ch10m 序幕加一句台词差分：
  "庞统：（信）云长轻敌，荆州危矣——统若在场，必谏……"（伏谏而不至）。
