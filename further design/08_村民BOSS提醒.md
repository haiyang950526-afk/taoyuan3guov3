# 08 · 村民 BOSS 提醒（对应 07 BOSS 机制设计）

> 目的：把 [07_BOSS机制与技能设计.md](07_BOSS机制与技能设计.md) 里每个 Boss 的"解法"，
> 提前通过村民/路人的闲谈透露给玩家——不看攻略也能靠"多听人说话"悟出打法。
>
> **本文档仅为设计稿，尚未接入游戏。** 主程序 agent 按"挂点"列接线。

## 写作与接线规范

1. **口吻必须是汉末百姓的口吻**：村民不懂数值，只会讲传闻、经验和俗话。
   - 禁词：防御、倍率、回合、抗性、机制、buff……一切游戏术语。
   - 翻译示例：07 写「def ×3」→ 村民说"刀砍上去直冒火星子"；
     07 写「每第 4 回合歇息」→ 村民说"打一阵就得歇口气"。
2. **每条 1~2 句，直接可粘贴**进地图 npcs 的 `lines` 数组（或 text.js 的 linesKey）。
3. **每条对应 07 的一个机制条目**：07 里砍掉哪个机制，这里的对应台词一并砍掉。
4. **不剧透精确数值与回合数**，只给方向性暗示（"趁早动手"、"先清两翼"）。
5. **挂点优先复用现有 NPC**（追加 lines）；现有 NPC 身份不合适的，标注"新增 NPC"
   并给出建议 id / 坐标风格（与所在图现有村民一致）。
6. 演出战（张辽、张飞误会战）与收服战（黄忠、马超、姜维）只提醒"怎么撑/怎么收"，
   不提醒输出手法——与 07 的原则一致。

## 接线备注（给主程序 agent）

1. **追加 vs 新增**：标"挂 XXX（追加 lines）"的，在对应地图文件该 NPC 的 `lines`
   数组尾部追加；原 NPC 用 `linesKey` 的（如小沛 v1/v2、山民 md_v），改在
   `data/text.js` 对应 key 的数组追加。标"新增 NPC"的，按同图现有村民的
   字段风格（color 用村民色系 `#9a8a6a` / `#8a7a9a` / `#7a8a9a`）添加。
2. **出现时机**：多数提醒常驻即可。两条建议挂 flag：
   - 夏侯惇提醒（新野老者 v2）：`appearIf: { flag: "q7", is: "start" }`，
     随报信兵一同出现，避免提前剧透；
   - 蔡瑁追兵提醒（襄阳城门老兵）：`appearIf: { flag: "q6", is: "xiangyang" }`
     （以实际任务 flag 为准）。
3. **不改动任何现有台词**，只追加/新增；与 01~06 文档条目冲突时以本文件为准。
4. 每条台词落地后，在 07 文档对应条目备注"村民提醒已接"，保持两份文档同步。
