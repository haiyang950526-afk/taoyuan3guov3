# 10 · 开放式选择 —— 麦城篇

> 目的：在 ch10「西川风云」（定军山，219 年春）与 ch11「出师未捷」（北伐，227 年）
> 之间，插入一章**多分支剧情章**——从孙权求婚到关羽突围，玩家步步抉择，
> 走出不同结局；但无论哪个结局，都要**合理地通向未来的"夷陵篇"**。
>
> **本文档仅为设计稿，尚未接入游戏。**

## 一、设计原则

1. **洪流原则：选择改变人物命运，不改变历史大势。** 荆州陷落是吕蒙、糜芳、
   曹操三方合力的结构性事件，玩家任何单一选择都挡不住——这和游戏终章
   "出师未捷"的悲剧基调一致。玩家的选择决定的是：**关羽怎么走到结局、
   谁活了下来、夷陵篇以什么遗产开局。**
2. **夷陵必然发生。** 所有结局共用同一逻辑：荆州已失 + 桃园之义（血仇或
   救弟）→ 刘备必伐吴。每个结局给出不同的"伐吴动机"，而非"是否伐吴"。
3. **演义为底本。** 节点、台词以《演义》第七十三~七十七回为骨架；玩家点名
   的"关平辩孟达"与演义（廖化突围）不符，本文档两者都支持——见节点五。
4. **选择有回响。** 前置选择累计成隐藏条件（诚意值），影响后续辩论成败、
   突围战难度、结局走向；每个选项都有代价，没有"白捡的最优解"。
5. **机制全部复用。** 引擎现有 `ask` 分支（河神斧头同款，选项可带任意
   `do` 动作）、`branches` 条件分支、`stash` 分线（长坂坡赵云单骑同款）、
   `scriptedLoss`（落凤坡同款）、`unbeatable + surviveRounds`（张辽同款）、
   `chain / waves / protect / forceEndRound`、结局 CG（章节插画同款）。
   唯一可选的引擎小改见第八节。

## 二、章节定位与流程总览

- 章节 key：`ch10m`（插章，不动现有编号）；显示名 **「间章 · 麦城悲歌」**；
  任务 flag：`q10m`。推荐等级 Lv47~50（接 ch10 毕业线）。
- POV：进章时用 `stash` 寄存主队，临时队伍 = **关羽 + 周仓 + 关平 + 廖化**
  （王甫任军师位）；章末按结局归还。关平/廖化/王甫/赵累为临时英雄。

```
定军山之后（q10 = done）
  └─ 序幕 · 樊城大捷（水淹七军 · 擒于禁，战）
       └─ 节点一 · 孙权求婚（选：痛骂 / 婉拒 / 许婚）
            └─ 节点二 · 陆逊的书信（选：看穿 / 将计就计 / 中计调兵）
                 └─ 节点三 · 治军（选：收押糜芳 / 扬言后治 / 温言安抚）
                      └─ 节点四 · 白衣渡江（不可选事件 + 徐晃战 → 退守麦城）
                           └─ 节点五 · 上庸求援（选使者：关平/廖化 → 辩孟达三选一）
                                └─ 节点六 · 突围（选：大路正战 / 小路伏击）
                                     ├─ 突围成功 → 结局贰/叁（生还线）
                                     └─ 被擒 → 节点七 · 孙权劝降（选：不屈 / 假降 / 降）
                                            ├─ 结局壹（就义）/ 结局肆（忍辱）/ 结局伍（伪结局）
```

**诚意值（隐藏条件）**：不用新机制，用三个布尔 flag 组合判定
（`mc_see` 看穿陆逊 / `mc_rule` 治军得当 / 节点五辩论选项），
`branches` 按顺序匹配第一个满足条件的分支，纯数据实现。

## 四、逐节点设计（触发点 / 对话 / 选项 / 机制）

> 台词均为可直接粘贴进 `data/text.js` 的格式，统一挂在 `ch10m.*` 命名空间下。

### 序幕 · 樊城大捷（水淹七军）

- **触发点**：`q10: done` 后回成都/江州任一主城，剧情使者来报：关羽围樊城，
  曹操遣于禁督七军来救。POV 切换（stash），镜头转荆州前线（新图
  `ch10m_fanying` 樊城蜀军营寨）。
- **战斗** `ch10m_fancheng`：`waves` 两波（先曹军先锋，后于禁本队），
  第 3 回合触发 `fire` 字段改文案演出**水攻**（机制复用，文案改为
  "秋雨暴涨，汉水决堤——七军尽没！"）。于禁复用旧敌人，lv/数值上调至
  本章线。战后演出：擒于禁、斩庞德（庞德抬榇死节一句带过，不单独做 Boss）。
- **战后台词**（text.js）：

```js
fanchengDone: ["（大水漫天，七军尽没。于禁束手就擒，庞德抬榇死节。）",
               "（一时之间，华夏震动——曹操几欲迁都以避其锋。）",
               "关羽：樊城旦夕可下！传令——",],
```

### 节点一 · 虎女焉能嫁犬子（求婚）

- **触发点**：樊城大捷后回营，NPC **诸葛瑾**（新 NPC，academic 色系）求见。
- **对话**：

```js
proposal: ["诸葛瑾：吴侯闻将军有女，淑德贤良——特遣瑾来，为世子求婚。",
           "诸葛瑾：两家结亲，共拒曹操，岂不美哉？",],
```

- **选项**（`ask`，选项带 `do` 动作，机制与河神斧头同款）：

| 选项 label | 效果（do） | 后续回响 |
|---|---|---|
| "虎女安肯嫁犬子！滚回去！" | `set mc_marriage=scold` | 历史台词。诸葛瑾灰溜溜回江东，孙权拍案。纯爽点，无数值影响 |
| "小女年幼，婚事容后再议。" | `set mc_marriage=decline` | 外交辞令。孙权面子上过得去，但吕蒙的密谋一天也没停（旁白点破：婚姻改不了荆州之争） |
| "孙刘本是一家——准了。" | `set mc_marriage=accept` + `set mc_yinping=1` | **假甜线**：关银屏赴吴待嫁。玩家以为改写了历史，白衣渡江照样发生（背刺更狠）；夷陵篇解锁"关银屏在吴"伏笔 |

- **各选项后续台词**：

```js
propScold:   ["关羽：吾虎女，安肯嫁犬子乎！回去告诉孙权——守好他的江东！",
              "诸葛瑾：这……这……（抱头鼠窜而去）",
              "（消息传回江东，孙权掷杯于地：好个红脸匹夫！）",],
propDecline: ["关羽：小女年幼，婚事……容后再议吧。",
              "诸葛瑾：既如此，瑾，这便回去复命。（躬身而退）",
              "（诸葛瑾走后，王甫低声：吴侯所图，恐不在婚约……）",],
propAccept:  ["关羽：孙刘本是一家。回去告诉吴侯——这亲事，关某准了。",
              "诸葛瑾：将军深明大义！吴蜀之好，泰山可倚！（大喜过望）",
              "（婚书既下。只是江东的密室里，吕蒙的地图，一夜也没有合上。）",],
```

### 节点二 · 陆逊的书信（骄兵计）

- **触发点**：求婚事件后，探马报：吕蒙称病回建业，**陆逊**代领陆口。
  陆逊遣使送书信名马，言辞极卑。
- **对话**：

```js
luxun: ["（陆逊书信：'将军神威，倾世无二。逊一介书生，唯将军马首是瞻……'）",
        "王甫：都督，吕蒙称病来得蹊跷，陆逊又卑辞厚礼——此中恐有诈。",
        "（是否抽调荆州守军，增援樊城前线？）",],
```

- **选项**：

| 选项 label | 效果 | 后续回响 |
|---|---|---|
| "孺子示弱，意在荆州——守军不动。" | `set mc_see=1`（诚意+1） | 看穿。江陵留赵累+半数守军；白衣渡江时江陵多守数日，突围战资源更好 |
| "将计就计：明抽调，暗布烽火。" | `set mc_see=2` | 中间档。守军照调，但烽火台加派暗哨；吕蒙偷袭时被烽火台咬掉半截先机 |
| "一介书生，何足为虑——调兵！" | 无 set | 历史线。荆州守军尽赴樊城，后方一空 |

### 节点三 · 治军（糜芳、傅士仁）

- **触发点**：节点二后，南郡军械库失火，粮草烧毁大半——糜芳、傅士仁失职，
  绑到帐前。
- **对话**：

```js
mifang: ["糜芳：都督饶命！是夜风大，火种失控……",
         "王甫（低声）：南郡、公安是荆州根本，此二人守的是命根子，处置不可不慎。",],
```

- **选项**：

| 选项 label | 效果 | 后续回响 |
|---|---|---|
| "重杖四十，糜芳收押！防务暂交赵累。" | `set mc_rule=1`（诚意+1） | 糜芳被押开不了城门；但公安傅士仁仍降（大势+虞翻说降），江陵被围后仍陷——**多守数日**，回援更从容 |
| "暂记此过——待我回来，再治尔等！" | 无 set | 历史线。"还当治之"四字，把二人推进了吕蒙怀里 |
| "胜败兵家常事，赐酒压惊，戴罪立功。" | `set mc_rule=2` | 二人暂安；吕蒙至，傅士仁仍降，糜芳犹豫半日——江陵巷战一日后陷落。夷陵篇糜芳线有台词回响 |

> 三选都保江陵陷落（洪流原则），差别只在**陷落速度**——它直接换算成
> 节点六突围战的初始资源（兵力/补给/回合数）。

- **战后台词**：

```js
             "关羽：……回军！先据麦城，再图后计！",],
```

### 节点五 · 上庸求援（选使者 → 辩孟达）

- **触发点**：麦城（新图 `ch10m_maicheng`）被围，粮草将尽。
- **第一步 · 选使者**（ask）：

| 选项 label | 效果 | 代价 |
|---|---|---|
| 关平去（"父亲守城，儿去上庸！"） | `set mc_envoy=guanping` | 守城战少一员主力（麦城守卫战难度↑）；但**亲情牌**辩论有加成（用户点名桥段） |
| 廖化去（演义正主） | `set mc_envoy=liaohua` | 守城阵容完整；辩论只能靠硬条件 |

- **第二步 · 上庸对峙**（新图 `ch10m_shangyong`，NPC 刘封、孟达）：

```js
shangyong: ["（上庸城中，刘封沉吟不语，孟达在侧冷笑。）",
            "孟达：呵呵……当年汉中王立嗣，你家关将军怎么说的？",
            "孟达：'螟蛉之子，不可僭立。'——这话，刘将军可还记着呢。",],
```

- **第三步 · 辩论三选一**（成败由前置诚意 + 使者决定，`branches` 顺序匹配）：

| 选项 label | 成功条件 | 说明 |
|---|---|---|
| "荆州若失，上庸唇亡齿寒——将军三思！"（大义） | `mc_see` 或 `mc_rule` 任一成立 | 点中孟达最怕的事：上庸孤悬。二人中至少一个有先见之明，这话才压得住 |
| "家父与汉中王桃园结义，将军忍见叔父赴死乎！"（亲情） | 使者 = 关平 | 亲儿子跪地哭诉才有效；廖化说出来分量不够 |
| "见死不救，汉中王必诛二将军！"（威吓） | 必败 | 孟达反被激怒（"吓唬我？"），且记恨 → 夷陵篇刘封线恶化 |

- **结果**：成功 → `set mc_liufeng=1`，刘封出兵五千接应（突围战难度大降，
  生还线必要条件之一）；失败 → 历史线，孟达按住刘封不发一兵。

```js
debateWin:  ["刘封：……罢了！点兵五千，我亲自接应叔父！",
             "孟达：将军！——唉！（拂袖）",],
debateLose: ["孟达：上庸新附，不可轻动。刘将军，请回吧。",
             "（使者望城恸哭，单骑而还。）",],
```

### 节点六 · 突围（大路 / 小路）

- **触发点**：求援结果落定，当夜突围。王甫谏：

```js
breakout: ["王甫：小路必设埋伏——君侯请走大路！",
           "周仓：俺随君侯多年，刀山火海，走哪条不是走！",],
```

- **选项**：

| 选项 label | 战斗 | 走向 |
|---|---|---|
| 走大路（听王甫的） | `ch10m_tuwei_big`：正面突围战 vs **潘璋 + 朱然**（双 Boss，硬仗但公平） | 胜 → 生还线；败 → 被擒线 |
| 走小路（历史选择） | `ch10m_tuwei_small`：临沮伏击战，马忠绊马索。默认 `scriptedLoss`；**若** `mc_liufeng=1` 且 `mc_see` 成立 → 转为可胜的普通战（伏兵被援军侧击） | 胜 → 生还线；败/剧情败 → 被擒线 |

- **战斗机制**：`chain` 连战（前哨→主将）+ `waves`；胜负分支走现有
  `onWin / onLoss` actions，按 flags 进不同结局，纯数据。
- **断后演出**（生还线必有代价）：周仓、王甫留守麦城——城破，
  王甫坠城、周仓自刎（台词见结局节）。

## 五、结局一览（全部通向夷陵）

| 结局 | 达成条件 | 演出要点 | 伐吴动机（夷陵篇开场） |
|---|---|---|---|

## 六、与夷陵篇的交接契约（flags）

夷陵篇开场只需读以下 flag，即可获得本篇章的全部遗产：

| flag | 取值 | 含义 |
|---|---|---|
| `mc_result` | `martyred / returned / fallen / feigned` | 结局（就义/归蜀/喋血/假降） |
| `mc_guanping` | `1` | 关平生还（仅结局贰） |
| `mc_yinping` | `1` | 关银屏在吴（节点一许婚）→ 夷陵篇救援/和谈伏笔 |
| `mc_marriage` | `scold / decline / accept` | 求婚处置 → 孙权方台词差分 |
| `mc_liufeng` | `1` | 刘封出过兵 → 夷陵篇刘封命运（历史：不救被赐死；出兵者可改为贬谪） |
| `mc_grudge` | `1` | 辩论选了威吓 → 孟达降魏线恶化 |

**为什么夷陵仍然合理（每种结局一句话）**：荆州已失是所有结局的共同底数；
壹/叁是血仇，贰是失地之恨，肆是救弟之义——刘备伐吴的动机永远成立，
变的只是**动机的内容和开局的阵容**。
