## 一、设计原则

1. **洪流原则：选择改变人物命运，不改变历史大势。** 荆州陷落是吕蒙、糜芳、
   曹操三方合力的结构性事件，玩家任何单一选择都挡不住——这和游戏终章
   "出师未捷"的悲剧基调一致。玩家的选择决定的是：**关羽怎么走到结局、
   谁活了下来、夷陵篇以什么遗产开局。**
2. **夷陵必然发生。** 所有结局共用同一逻辑：荆州已失 + 桃园之义（血仇或
   救弟）→ 刘备必伐吴。每个结局给出不同的"伐吴动机"，而非"是否伐吴"。
3. **隐忍暗线：委曲求全保命，不挡刀兵。** 节点一"许婚"被刻意包装成
   最像"正确答案"的选项（隐晦引导，不点破）。一路忍让的玩家改变不了
   白衣渡江——但婚约会在节点七兑现：**孙权顾念婚约，不杀关羽**（保底软禁）。
   硬气的玩家走历史就义线，隐忍的玩家走保命线，都合理。
4. **演义为底本。** 节点、台词以《演义》第七十三~七十七回为骨架。
   两处与用户点名的出入按用户口径处理：求援使者可用关平（演义为廖化，
   两者都支持，见节点五）；关平按演义设定为**义子**（第二十八回，关定之子
   随关羽）——这是节点五"共情"选项的依据。
5. **选择有回响。** 前置选择累计成隐藏条件（诚意值），影响后续辩论成败、
   突围战难度、结局走向；每个选项都有代价，没有"白捡的最优解"。
6. **机制全部复用。** 引擎现有 `ask` 分支（河神斧头同款，选项可带任意
   `do` 动作）、`branches` 条件分支、`stash` 分线（长坂坡赵云单骑同款）、
   `scriptedLoss`（落凤坡同款）、`chain / waves / protect / forceEndRound`、
   结局 CG（章节插画同款）。引擎小改只有两处，见第七节。

## 二、章节定位与流程总览

- 章节 key：`ch10m`（插章，不动现有编号）；显示名 **「间章 · 麦城悲歌」**；
  任务 flag：`q10m`。推荐等级 Lv47~50（接 ch10 毕业线）。
- POV：进章时用 `stash` 寄存主队，临时队伍 = **关羽 + 周仓 + 关平 + 廖化**
  （王甫任军师位）。章末归还主队——**但关羽一律不再归还**（无论结局，
  从此退出战斗序列，见第五节"关羽离队"）。关平/廖化/王甫/赵累为临时英雄。

```
定军山之后（q10 = done）
  └─ 序幕 · 樊城大捷（水淹七军 · 擒于禁，战）
       └─ 节点一 · 孙权求婚（选：痛骂 / 婉拒 / 许婚★引导项，埋伏笔）
            └─ 节点二 · 陆逊的书信（选：看穿 / 将计就计 / 中计调兵）
                 └─ 节点三 · 治军（选：收押糜芳 / 扬言后治 / 温言安抚）
                      └─ 节点四 · 白衣渡江（傅士仁必降；糜芳视节点三处置）
                           └─ 节点五 · 上庸求援（选使者：关平/廖化 → 三轮辩论）
                                └─ 节点六 · 突围（选：大路正战 / 小路伏击）
                                     ├─ 突围成功 → 结局贰/叁（生还线）
                                     └─ 被擒 → 节点七 · 孙权劝降（选：不屈 / 假降 / 降）
                                            ├─ 未许婚 → 结局壹（就义）/ 肆（假降）/ 伍（伪结局）
                                            └─ 已许婚 → 保底结局肆（软禁保命）
```

**诚意值（隐藏条件）**：不用新机制，用布尔 flag 组合判定
（`mc_see` 看穿陆逊 / `mc_rule` 治军得当 / 辩论各轮 `mc_d1~d3`），
`branches` 按顺序匹配第一个满足条件的分支，纯数据实现。

### 节点一 · 虎女焉能嫁犬子（求婚 · 许婚为隐晦引导项）

- **触发点**：樊城大捷后回营，NPC **诸葛瑾**（新 NPC）求见。
- **引导设计（不点破）**：对话里让"许婚"听起来是顾全大局的明智之举——
  诸葛瑾陈以利害，连一向谨慎的王甫都低声附和；同时埋下一句"刀兵休提"
  的承诺，成为节点七保命的伏笔。骂使选项保留原味（玩家都知道那是"关羽
  会说的话"），但气氛上让它显得冲动。玩家事后才会发现：婚约挡不住吕蒙，
  却挡得住孙权的刀。
- **对话**：

```js
proposal: ["诸葛瑾：吴侯闻将军有女淑德，特遣瑾来，为世子求婚。",
           "诸葛瑾：曹操方炽，孙刘唇齿——两家结亲，荆州安如泰山，将军北伐亦无后顾之忧。",
           "王甫（低声）：都督，大敌当前，多一门亲事，总好过多一个仇家……",
           "诸葛瑾：吴侯还有一言：婚姻既结，荆州便是两家之荆州——刀兵二字，从此休提。",],
```

- **选项**（`ask`，选项带 `do` 动作，机制与河神斧头同款）：

| 选项 label | 效果（do） | 后续回响 |
|---|---|---|
| "虎女安肯嫁犬子！滚回去！" | `set mc_marriage=scold` | 历史台词。诸葛瑾抱头鼠窜，孙权掷杯。纯爽点，无数值影响 |
| "小女年幼，婚事容后再议。" | `set mc_marriage=decline` | 外交辞令。孙权面上过得去，吕蒙的密谋一天没停（旁白点破：婚姻改不了荆州之争） |
| "好。孙刘既为唇齿——这亲事，关某准了。" | `set mc_marriage=accept` + `set mc_yinping=1` | **引导项/假甜线**：关银屏赴吴待嫁。玩家以为改写了历史，白衣渡江照样发生；但节点七孙权顾婚约不杀（**保底保命**），且夷陵篇解锁"关银屏在吴"伏笔 |

- **各选项后续台词**：

```js
propScold:   ["关羽：吾虎女，安肯嫁犬子乎！回去告诉孙权——守好他的江东！",
              "诸葛瑾：这……这……（抱头鼠窜而去）",
              "（消息传回江东，孙权掷杯于地：好个红脸匹夫！）",],
propDecline: ["关羽：小女年幼，婚事……容后再议吧。",
              "诸葛瑾：既如此，瑾，这便回去复命。（躬身而退）",
              "（诸葛瑾走后，王甫低声：吴侯所图，恐不在婚约……）",],
propAccept:  ["关羽：孙刘本是一家。回去告诉吴侯——这亲事，关某准了。",
              "诸葛瑾：将军深明大义！'刀兵休提'四字，瑾，必字字带到！（大喜过望）",
              "（婚书既下。这句话，关平记下了，周仓记下了。）",
              "（但愿江东，也记着。）",],
```

### 节点三 · 治军（糜芳、傅士仁）

- **触发点**：节点二后，南郡军械库失火，粮草烧毁大半——糜芳、傅士仁失职，
  绑到帐前。
- **对话**：

```js
mifang: ["糜芳：都督饶命！是夜风大，火种失控……",
         "王甫（低声）：南郡、公安是荆州根本，此二人守的是命根子，处置不可不慎。",],
```

- **选项**：

| 选项 label | 效果 | 后续回响 |

### 关羽离队（所有结局统一）

- **无论哪个结局，关羽从此退出战斗序列**——就义与软禁自不必说；

```js
guanyuRetire: ["（成都。关羽解下青龙偃月刀，双手奉于殿上。）",

               "（那柄刀从此悬在武侯祠的梁上。再无人见它出鞘。）",],
```

- **机制**：章末 stash 归还主队时，关羽不归还——需一个引擎小动作
  `{ leave: "关羽" }`（从队伍/后备中永久移除并触发交代台词，~10 行）。
  这是本章**唯一的必需引擎改动**。
- 关平若生还（结局贰，`mc_guanping=1`）可留队继承父志——生还线的

## 六、与夷陵篇的交接契约（flags）

夷陵篇开场只需读以下 flag，即可获得本篇章的全部遗产：

| flag | 取值 | 含义 |
|---|---|---|
| `mc_result` | `martyred / returned / fallen / feigned` | 结局（就义/归蜀/喋血/软禁） |
| `mc_guanping` | `1` | 关平生还（仅结局贰）→ 可入队 |
| `mc_yinping` | `1` | 关银屏在吴（节点一许婚）→ 婚约保命伏笔 + 夷陵篇救援/和谈伏笔 |
| `mc_marriage` | `scold / decline / accept` | 求婚处置 → 孙权方台词差分 |
| `mc_rule` | `1 / 2` | 治军处置 → 糜芳名节（1=未做叛徒）→ 夷陵篇糜芳台词差分 |
| `mc_liufeng` | `1` | 刘封出过兵 → 夷陵篇刘封命运（历史：不救被赐死；出兵者可改为贬谪） |
| `mc_grudge` | `1` | 辩论选了威吓 → 孟达降魏线恶化 |

**为什么夷陵仍然合理（每种结局一句话）**：荆州已失是所有结局的共同底数；
壹/叁是血仇，贰是失地之恨，肆是救弟之义——刘备伐吴的动机永远成立，
变的只是**动机的内容和开局的阵容**。
