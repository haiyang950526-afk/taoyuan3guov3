# 07 · BOSS 机制与技能设计（历史梗驱动）

> 目的：解决 Boss 战"纯平 A"问题。每个 Boss 给一个**历史梗 → 战斗机制 → 反直觉解法**，
> 让玩家用现有工具（计策、阵型、特定角色、道具）打出"啊，原来是这一仗"的感觉。
>
> 样板（用户原案）：火烧博望坡——夏侯惇基础防御 ×3（平 A 打不动），遇火计伤害 ×6
> （逼玩家用计）。本文档把这一思路推广到全部 Boss。
>
> **本文档仅为设计稿，尚未接入游戏。**

## 设计原则

1. **机制是捷径，不是门槛。** 不用机制、靠等级和补给硬打，仍然能过（现有数值即兜底）；
   用对机制，回合数显著缩短、消耗显著降低。演出战（unbeatable/scriptedLoss）和收服战
   （recruit）只加彩蛋，不动胜负手。
2. **数值红线不破。** Boss 战时长维持 `enemies.js` 头部约定的 8~12 回合；
   计策弱点倍率 ≤ ×6；敌侧抗性 ≤ 60%；每场 Boss 战 **1 个主机制 + 至多 1 个彩蛋**。
3. **引擎读 schema，不写死。** 沿用 `enemies.js` 既有约定（ai / skill / phases / fire /
   chain / waves / recruit / forceEndRound），新机制一律做成通用数据字段，全体 Boss 复用。
4. **克制关系只用玩家已有的牌**：通用计策（火计/落石/水计）、计策书（风/雷）、
   诸葛亮（八卦阵/东风/星落）、张飞大喝、阵型计策抗性、特定角色在场（历史克制彩蛋）。

## 引擎需新增的通用机制（一次实现，全体复用）

| 字段（建议名） | 挂点 | 语义 | 首次使用者 |
|---|---|---|---|
| `weakMagic: { huoji: 6, ... }` | ENEMIES | 指定计策对该敌伤害倍率（与地形 ×1.5 叠乘） | 夏侯惇 |
| `magicResist: 0.5` / `physResist: 0.5` | ENEMIES | 敌侧计策/物理减伤（0~0.6） | 姜维、司马懿 |
| `heroLink: [{ hero, mult, say }]` | ENEMIES | 指定角色在场/攻击时的伤害倍率与台词（历史克制彩蛋） | 关羽→颜良 |
| `script: [{ round, say?, effect }]` | BATTLE_GROUPS | 回合脚本：`fire` 的泛化，支持属性变化/演出/条件分支 | 车胄、卞喜 |
| `summon: { enemy, everyRounds }` 或 phase 触发 | ENEMIES | 召唤小怪 | 黄巾头目、赵慈 |
| `enemySureHit` 技能类型 | SKILLS | 必中、无视防御、可固伤（冷箭类） | 韩福、黄忠 |
| `enemyMagic` / `enemyMagicAll` 扩展 | SKILLS | 敌方释放地形计策（落石/夜火），`tianming` 类型复用调数值 | 王植、张任 |
| `counter: 0.2` | ENEMIES | 被物理攻击反伤比例 | 司马懿二形态 |
| `atkGrow: 0.06` | ENEMIES | 每回合攻击叠乘成长（怒气） | 马超 |
| `stanceCycle: [守, 攻]` | ENEMIES | 每回合切换姿态（属性互换）+ 提示 | 张郃 |
| `flee: { hpBelow, rounds }` | ENEMIES | 低血逃跑窗口：限时未杀则脱战（胜利但无掉落） | 秦琪 |
| `doubleAction: 0.3` | ENEMIES | 每回合概率二次行动 | 虎豹骑 |
| `selfDot: 0.05` | phases / ENEMIES | 每回合自损最大 HP 比例 | 孙礼、金旋 |

> 实现成本集中在 `engine/battle.js` 的行动选择与结算两处；以上字段全部缺省即现状，
> 旧数据零迁移。

## 逐 Boss 设计

### 序章 · 黄巾头目（ch00_boss）

- **梗**：黄巾以太平道聚众生事，靠人多。
- **机制「妖道聚兵」**：每 3 回合，若场上小怪少于 2，召唤 1 名黄巾贼（lv1，hp30）。
- **解法**：不管小兵、直取头目——头目一死召唤即停。给新手的第一课：集火。
- **改动**：`summon: { enemy: "黄巾贼", everyRounds: 3, maxOnField: 2 }`。

### 一章 · 于禁（ch01_boss，已有整肃）

- **梗**：于禁持军严整；晚年水淹七军降关羽（此处埋伏笔）。
- **机制「军阵」**：两侧小怪存活时，于禁 def ×1.5（军阵未破）。
- **彩蛋**：水计对他 ×2（台词：于禁：水……？不，不可能——）。
- **解法**：先清小怪破阵，或水计偷伤害。整肃保留。
- **改动**：光环（友军存活 → statsMult）+ `weakMagic: { shuiji: 2 }`。

### 二章 · 纪灵（ch02_boss，已有 hpBelow 0.3 狂暴）

- **梗**：与关羽大战三十合不分胜负，大叫"少歇！"。
- **机制「大叫少歇」**：每第 4 回合歇息（不行动、回血 5%），次回合必放 ×2 重击。
- **解法**：歇息回合是免费输出窗口；算准节奏在第 4 回合前压血。
- **改动**：`script` 回合循环；现有 heavy ai 与 phases 保留。

### 二章 · 张辽（ch02_zhangliao，演出战）

- 不动胜负手。彩蛋：张辽必定先手（spd 演出拉高）+ 一句"奉先麾下张辽，领教！"即可。

### 三章 · 车胄先锋（ch03_tuwei）

- **梗**：刘备军诈称曹公回城，赚开城门。
- **机制「措手不及」**：第 1 回合敌方全体 spd ×0.5（城门初破，立足未稳）。
- **解法**：开局把最强的技能全砸出去。
- **改动**：`script: [{ round: 1, effect: { spdMult: 0.5 } }]`。

### 四章 · 车胄（ch04_chezhou2）

- **梗**：陈登内应，关羽赚城斩车胄。
- **机制「内应」**：第 2 回合起车胄 def ×0.6 至战斗结束（城门已失，腹背受敌）。
- **彩蛋**：关羽对车胄伤害 ×1.5（台词呼应赚城）。
- **解法**：第 1 回合补给上 buff，第 2 回合起总攻。
- **改动**：`script` + `heroLink: [{ hero: "关羽", mult: 1.5 }]`。

### 四章 · 颜良 → 文丑（ch04_yanliang / ch04_wenchou，连战）

- **颜良·梗**：白马之围，勇冠三军；关羽策马刺良于万众之中。
  - 机制「河北骁勇」：前 2 回合 atk ×1.4。
  - 彩蛋「斩颜良」：关羽在场时，颜良优先攻击关羽但命中 -20%（胆寒）；
    关羽对颜良伤害 ×3。
  - 解法：前两回合防守顶住，之后保关羽收割。
- **文丑·梗**：延津诱敌，军士抢辎重阵型大乱，被关羽三合斩之。
  - 机制「抢辎重」：开场 2 回合 def ×0.5（军乱）；若 2 回合内未打下 50% 血，
    第 3 回合起「整队」atk ×1.2（惩罚拖沓）。
  - 彩蛋：关羽对文丑 ×2。
  - 解法：开场全力爆发，窗口内压死。
- **改动**：`heroLink`（双向：伤害倍率 + 仇恨/命中修正）、`script` 时限 buff。

### 五章 · 五关守将（ch05_kongxiu / hanfu / bianxi / wangzhi / qinqi）

- **孔秀**（东岭关，一合被斩）：轻量开门炮。「虚张声势」开场 atk ×1.3；
  首次低于 50% 血「胆裂」spd/def -30%。解法：一轮高攻压血线。改动：phases 复用即可。
- **韩福**（冷箭射伤关羽左臂）：「冷箭」每 3 回合对当前 HP 最高者放必中箭，
  无视防御、固伤 ≈ 目标上限 10%。彩蛋：关羽在场时首箭必射关羽（"左臂！"）。
  解法：3 回合内压杀，或防御姿态/八卦阵吃箭。改动：`enemySureHit`。
- **卞喜**（镇国寺设伏，普净示警）：「诈降设伏」前 2 回合不攻击只防御（def ×1.5），
  第 3 回合「掷杯为号」×1.8 全体攻击。彩蛋「计谋败露」：若前 2 回合玩家总输出
  超过其 HP 30%，第 3 回合爆发取消且 spd -50%。解法：识破就猛攻；
  没识破就第 2 回合全员防御/补给迎爆发。改动：`script` 条件分支。
- **王植**（夜烧馆驿，胡班告密）：「夜火」第 3 回合对我方全体火伤（弱版 enemyMagicAll）。
  解法：第 3 回合前击杀则火放不出——速杀检查战。改动：`enemyMagicAll` 调数值复用。
- **秦琪**（黄河渡口口出狂言，一合被斩）：「嘴硬心虚」50% 血以上 atk ×1.2；
  低于 30%「夺船欲逃」spd ×2，2 回合内未击杀则脱战（战斗算胜，但无掉落）。
  解法：留一发青龙斩/蛇矛突收头。改动：`flee`。
- **裴元绍**（ch05_peiyuan，夺马遇赵云）：「一遇赵子龙」优先攻击赵云（atk ×1.3），
  赵云对他伤害 ×2。解法：赵云主 C。改动：`heroLink` + 仇恨钩子。
- **张飞(误会)**：演出战，不动。

### 六章 · 新野（ch06_bandit1/2/3, ch06_caimao）

- **匪首张武**（的卢马！）：「的卢」spd ×1.5 + 15% 物理闪避；击杀掉新饰品
  **的卢马**（spd+5，呼应 04 名品收藏）。彩蛋：赵云对其 ×1.5（"子龙夺马"）。
  解法：计策不吃闪避，谋士输出。改动：闪避字段 + items.js 加 1 行 + 掉落。
- **匪首陈孙**：「复仇」若张武已被讨伐（读 flag），开场 atk ×1.3。
  解法：玩家可自选先打谁——先打陈孙就没有复仇 buff。改动：`script` 读 flag。
- **匪首赵慈**：「落草为寇」hpBelow 0.4 召唤 2 名新野匪徒。
  解法：爆发跳过血线，或留偃月横扫。改动：`summon`（phase 触发）。
- **蔡瑁追兵**（的卢跃檀溪）：`forceEndRound: 3`——撑 3 回合后演出"的卢一跃三丈"脱战。
  改动：**复用现有字段**，只加演出文本。

### 七章 · 夏侯惇（ch07_bowang）——样板，用户原案

- **梗**：火烧博望坡。
- **机制「轻敌铁壁」**：基础 def ×3（36 → 108，轻敌冒进却扎得稳，平 A 流受阻）。
- **机制「遇火则焚」**：`weakMagic: { huoji: 6, dongfeng: 6 }`；第 3 回合剧情火
  （`fire` 已有，dmg 建议 800 → 1500）后，夏侯惇 def 复原（烧伤，呼应"中计了！"）。
- **解法**：全员 Lv6 已会火计——前两回合火计磨 + 补给，第 3 回合剧情火起后总攻。
  平 A 硬磨仍可过（hp 3800 兜底），但要 12+ 回合且补给吃紧。
- **改动**：`weakMagic` + 数据改 def + `fire` 数值 + 火后 def 复原 script。
- **备注**：现有文本（bossHalf"中计了"、fireSay）天然契合，台词基本不用新增。

### 七章 · 虎豹骑（ch07_cb4/cb5，waves）

- **梗**：曹纯麾下天下骁锐，长坂一日一夜行三百里。
- **机制「奔袭」**：每回合 30% 概率二次行动（追骑咬尾）。
- **解法**：八卦阵/防御位顶住爆发，波次间补给节奏是关键。
- **改动**：`doubleAction: 0.3`。

### 八章 · 水师都督（ch08_chibi，已有 fire round2）

- **梗**：铁索连环，火烧赤壁。
- **机制「铁索连环」**：敌方全体受单体伤害 ×0.7（船船相护）；
  但火计/东风伤害 ×3，且「连环延烧」——任一敌受火伤时，其余敌人受 30% 溅射。
- **解法**：第 2 回合剧情火 + 东风/火计连环引爆，一波清场；平 A 打连环船极亏。
- **改动**：`weakMagic: { huoji: 3, dongfeng: 3 }` + 火伤溅射钩子。

### 八章 · 曹操亲卫队（ch08_huarong，已有 forceEndRound 6）

- **梗**：华容道，败军之将，关羽义释曹操。
- **机制「残兵死战」**：全体 atk ×0.7，亲卫队 def ×1.3。
- **彩蛋「云长之威」**：关羽在场时，敌方每回合 atk 再 -10%（最多叠 3 层）。
- **解法**：防守拖 6 回合走义释演出（现有逻辑），或硬打也可——彩蛋只加味道。

### 九章 · 荆南（ch09_guiyang / wuling / huangzhong）

- **赵范部将**（鲍隆陈应诈降）：「诈降」第 2 回合停手求降（不行动）；

- **金旋**（巩志射杀金旋献城）：「众叛亲离」hpBelow 0.35 时 def ×0.6 且每回合自损 3%。

- **黄忠(敌)**（收服战）：「箭囊」开场 5 支箭，每回合 1 支「百步穿杨」必中射血最少者；

  "还君不杀之恩"伏笔）。recruit 逻辑不变。解法：拖完 5 箭或快速压到 30% 收服。
  改动：`enemySureHit` + 弹药计数。

### 十章 · 西川（ch10_zhangren / machao / dingjun / zhanghe）
